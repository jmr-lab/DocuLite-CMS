Estancia CMS

Estancia is a Content Management System (CMS) written in PHP and currently using a MySQL database (it can also use an Oracle or MS SQL Server database).

This project was originally a modification of the JBC Explorer, to add a layer of security to this explorer (using user authentication). After several years the Estancia project became totally different: it is now using a database to manage the metadata and a filesystem to store the object's contents.
Estancia also uses different open-source technologies such as jQuery. The user interface is based on the icon theme provided by Everaldo.
Due to the author's knowledge of Documentum, it was easier to build a system compatible with this CMS.

It's using almost the same tables as Documentum, but intends to be faster. The only differences are some attributes are using IDs instead of names. For example the Documentum attribute 'acl_name' of the table 'dm_sysobject_s' has been replaced by 'acl_id'. The main advantage is that one can rename an ACL 'on the fly', there is no need to run a job after changing an ACL name.

It's amazing how the latest versions of Documentum can use that much memory, and need several powerful servers to run. With Estancia you can forget such needs!

Top Repository.

Like in Windows, Mac or Linux, all files are stored in folders, themselves stored in other folders.
The top folders, stored under the "root" folder, or "C: drive" for those familiar with Windows, are named "cabinet".
The root folder, called repository, can only contain cabinets. All documents and other objects must be stored under subfolders.

For now you can use this CMS as you would use the Windows explorer :

  • Click on a folder to open it,
  • Use the shift or control keys for multiple selection,
  • Right click on a document or folder to see the possible actions available.
I have given you, the 'Guest' user, the ability to create documents in the 'Public' folder.
Please note that I keep the right to remove any file that I would consider inappropriate.

Due to some limitations with Free.fr (free hosting provider) it is not possible with this demo to use scheduled jobs.
This impacts the workflow engine and the index engine (limited search capabilities).
You can still see in the 'Workflows' menu that it is possible to create Quickflows (when you submit a new comment in the contact form).
